# ESP32 智能 LED 像素屏：从入门到精通 (20 课时学习大纲)

本大纲旨在引导你从零开始，逐步掌握嵌入式硬件驱动、物理模拟算法、网络协议栈及人工智能硬件联动的全栈技能。

---

## 第一部分：硬件起步与外设驱动 (课时 1-5)
**核心目标：掌握 ESP32 的基本开发环境及底层传感器通信。**

1.  **第 1 课：环境搭建与工程解析**
    *   了解 ESP-IDF 开发环境、CMake 构建系统。
    *   解析本项目的 `main`、`components` 目录结构。
2.  **第 2 课：GPIO 与按键状态机**
    *   学习 GPIO 的输入模式与上拉电阻。
    *   实现非阻塞的按键扫描及长按检测逻辑（参考 `main.c` 任务）。
3.  **第 3 课：I2C 协议与 MPU6050 传感器**
    *   I2C 协议原理：起始位、寻址、数据传输。
    *   读取传感器原始数据（Acc/Gyro）。
4.  **第 4 课：WS2812 驱动原理与 RMT 外设**
    *   单总线归零码时序解析。
    *   学习 `led_strip` 组件的使用及像素点寻址。
5.  **第 5 课：二维像素映射与坐标变换**
    *   将 8x8 物理布局映射到内存一维数组。
    *   实现基础图形（点、线、矩形）的绘制函数。

---

## 第二部分：RTOS 多任务与系统调度 (课时 6-8)
**核心目标：理解单片机上的“并发”与资源管理。**

6.  **第 6 课：FreeRTOS 任务创建与生命周期**
    *   `xTaskCreate` 参数详解：优先级、栈空间、内核内核绑定。
    *   防止任务看门狗触发导致的崩溃。
7.  **第 7 课：任务间通信：队列与信号量**
    *   如何将传感器的重心数据安全地传递给渲染引擎。
    *   互斥锁解决共享显示缓冲区的竞争问题。
8.  **第 8 课：非易失性存储 (NVS) 实战**
    *   在 Flash 中保存 Wi-Fi 账密。
    *   实现设备下电后依然保存上次运行模式的功能。

---

## 第三部分：数学与物理模拟引擎 (课时 9-13)
**核心目标：赋予灯板“灵魂”，实现逼真的动态效果。**

9.  **第 9 课：姿态解算与重力分量提取**
    *   理解加速度计在静态下的重力表现。
    *   计算简单的倾斜角度，为物理方程提供输入。
10. **第 10 课：火焰特效：元胞自动机算法**
    *   数值模拟：热量扩散模型与随即扰动。
    *   解析程序中火焰模式的色域映射实现。
11. **第 11 课：流体力学基础：粒子法与网格法**
    *   什么是质点？什么是重力在液体中的矢量驱动？
    *   解析 `Middlewares/FLIP` 组件的设计思路。
12. **第 12 课：流体碰撞处理与物理步进**
    *   边界条件控制：当“水流”撞击屏幕边缘时的反弹。
    *   时间步（dt）对数值稳定性的影响。
13. **第 13 课：平滑切换：引擎状态调度器**
    *   `sim_manager` 模式切换时的资源清理与重置。
    *   实现各模式间的内存复用技巧。

---

## 第四部分：网络通信与嵌入式 Web 服务器 (课时 14-17)
**核心目标：让硬件“出圈”，实现远程交互与路由功能。**

14. **第 14 课：Wi-Fi AP/STA 混合模式**
    *   理解 SoftAP 的工作原理与网段分配。
    *   实现前端与后端的初始握手沟通。
15. **第 15 课：嵌入式 HTTP 服务端实现**
    *   HTTP GET/POST 路由注册。
    *   解析 URL 参数与 JSON Body 载荷。
16. **第 16 课：嵌入式全栈：HTML 字符串与 CSS 布局**
    *   如何将海量前端代码嵌入 C 语言数组。
    *   JS 异步 Fetch API 与后端的 API 交互逻辑。
17. **第 17 课：NAT 路由转发与网络拓扑**
    *   启用 LwIP 的 NAPT 功能。
    *   让连接到灯板的设备能够通过灯板连接的主路由上网。

---

## 第五部分：AI 大模型 AIoT 联动 (课时 18-20)
**核心目标：迈向智能硬件的终极形态。**

18. **第 18 课：HTTPS 客户端与智谱 API 对接**
    *   处理 SSL/TLS 证书（`esp_crt_bundle`）。
    *   构造符合 OpenAI 标准的 API 请求头与 JSON 数据。
19. **第 19 课：提示词工程 (Prompt Engineering) 进阶**
    *   System Prompt 的结构化设计。
    *   引导 AI 输出结构化控制报文（JSON）的技巧。
20. **第 20 课：意图执行：从对话到硬件动作**
    *   前端解析 AI 返回的 Bitmap 位图。
    *   全流程回顾：从“说句话”到“灯板画出相应图案”。
